##  Getting Started

###  Prerequisites

Before getting started with aplicacion_de_peliculas, ensure your runtime environment meets the following requirements:

- **Programming Language:** TypeScript
- **Package Manager:** Npm


###  Installation

Install aplicacion_de_peliculas using one of the following methods:

**Build from source:**

1. Clone the aplicacion_de_peliculas repository:
```sh
❯ git clone https://github.com/pongf456/aplicacion_de_peliculas
```

2. Navigate to the project directory:
```sh
❯ cd aplicacion_de_peliculas
```

3. Install the project dependencies:


**Using `npm`** &nbsp; [<img align="center" src="https://img.shields.io/badge/npm-CB3837.svg?style={badge_style}&logo=npm&logoColor=white" />](https://www.npmjs.com/)

```sh
❯ npm install
```




###  Usage
Run aplicacion_de_peliculas using the following command:
**Using `npm`** &nbsp; [<img align="center" src="https://img.shields.io/badge/npm-CB3837.svg?style={badge_style}&logo=npm&logoColor=white" />](https://www.npmjs.com/)

```sh
❯ npm start
```


###  Testing
Run the test suite using the following command:
**Using `npm`** &nbsp; [<img align="center" src="https://img.shields.io/badge/npm-CB3837.svg?style={badge_style}&logo=npm&logoColor=white" />](https://www.npmjs.com/)

```sh
❯ npm test
```

   ```sh
   git clone https://github.com/pongf456/aplicacion_de_peliculas
   ```
3. **Create a New Branch**: Always work on a new branch, giving it a descriptive name.
   ```sh
   git checkout -b new-feature-x
   ```

4. **Make Your Changes**: Develop and test your changes locally.

   ```sh
   git commit -m 'Implemented new feature x.'
   ```
